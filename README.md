# OVA #12 – El Enfoque Sistémico
### Teoría General de Sistemas · Universidad Simón Bolívar – Cúcuta

## Descripción

Objeto Virtual de Aprendizaje (OVA) desarrollado como proyecto final de la asignatura **Teoría General de Sistemas (TGS)**. El tema asignado es **El Enfoque Sistémico**, abordado desde sus fundamentos teóricos, aplicaciones reales y actividades interactivas.

## Contenidos de la OVA

| Módulo | Descripción |
|---|---|
| Conceptos | 6 tarjetas interactivas con los principios clave del Enfoque Sistémico |
| Teoría | Marco teórico con citas de Bertalanffy, Senge, Wiener y más |
| Diagrama | Diagrama ICOM interactivo (clic en cada componente para info) |
| Ejemplos | 3 casos reales: Salud Pública, Empresa, Ecosistema (Yellowstone) |
| ejercicios | 4 ejercicios con retroalimentación inmediata |
| uego 1 | ¿Sistémico o Reduccionista? – con vidas y puntaje |
| Juego 2 | Conecta Concepto-Definición – emparejamiento visual |
| Juego 3 | Quiz cronometrado de 10 preguntas con puntaje automático |
| Videos | 3 videos educativos curados de YouTube |
| Créditos | Ficha del autor y 7 referencias bibliográficas APA |
